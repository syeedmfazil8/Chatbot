# Chatbot
Fazil AI — Chatbot

A modern, professional AI chatbot built with FastAPI, Groq, and Llama. Features a sleek dark UI with markdown rendering, syntax-highlighted code blocks, typing indicators, and conversation memory.

✨ Features
🎨 Modern dark UI — glassmorphism, gradients, smooth animations

💬 Real-time chat — instant responses with typing indicator

📝 Markdown support — bold, italics, lists, links, blockquotes

💻 Syntax highlighting — code blocks rendered with highlight.js

📋 Copy button — one-click copy on every bot reply

🕒 Timestamps — every message shows when it was sent

🔄 New Chat button — reset conversation anytime

📱 Fully responsive — looks great on mobile and desktop

⚡ Fast — powered by Groq's ultra-fast inference

🧠 Conversation memory — bot remembers the whole conversation
